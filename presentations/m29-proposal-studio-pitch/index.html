LA SOLUCIÓN 03 / 09
M29 Proposal Studio

Un sistema modular
para armar propuestas en 20 minutos.

Cuatro etapas. Output HTML dinámico (animado, con charts vivos) + PDF para envío. Branding consistente. Reuso real entre clientes.

PASO 1

Selección

El director elige cliente, tipo de oportunidad y los módulos relevantes del catálogo.

PASO 2

Inputs

Pega data de Atom11, Data Dive, H10 o sube un screenshot. El módulo lo parsea.

Engine
M29Proposal Studio
PASO 3

Render

Genera HTML dinámico standalone con animaciones, scroll-snap y Chart.js.

PASO 4

Export

Descarga HTML para mostrar en vivo o PDF para mandar al lead por mail.

CÓMO LO USAN 06 / 09
Workflow del sales director

De cero a propuesta lista
en menos de 20 minutos.

Cuatro pantallas. Sin tocar diseño. Sin pelearse con un PowerPoint que no respeta el branding.

01

Elegí cliente

Cliente nuevo o existente. El sistema trae nombre, logo y branding desde el config.

~ 1 min
02

Marcá módulos

Checkbox sobre los 27 módulos. El sistema sugiere defaults según el tipo de cliente.

~ 2 min
03

Llenás inputs

Pegás CSV de Atom11 o Data Dive. Subís imágenes para audits. Texto libre donde haga falta.

~ 12 min
04

Exportás

HTML standalone para mostrar en call. PDF para mandar por mail. Ambos con el mismo branding.

~ 30 seg
