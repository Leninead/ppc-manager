## Gotchas descubiertos

- **Encoding PowerShell + git redirects**. Los commands con redirect `>` o pipes en PowerShell mezclan encoding y rompen git output. Workaround: usar `cmd /c` para los comandos git que usen pipes/redirects, o Bash directamente (ya disponible en esta máquina). Aplicado varias veces esta sesión cuando `git mv` con paths que tenían `#` (`Slack #learnings-implementations.md`) o espacios (`Atom11_Template (1).md`).
- **sop-writer omitiendo archivos gemelos silenciosamente**. Detectado al revisar `git status` después de que el agente reportó "ambos INTELLIGENCE-INDEX actualizados" — solo el de raíz había cambiado. Regla aplicada y documentada en [[module-architecture-standard]]: nunca confiar en output de sub-agent sin verificar con `git diff --stat`. Es el mismo bug que se documentó ayer en la sesión 2026-04-23 para `ppc-module-builder`.
- **sop-writer reportando métricas infladas**. Dijo "121→166 líneas" en ppc-reporting-standard.md pero `wc -l` devolvió 133. Dijo "140→181" en module-architecture-standard.md pero son 149. El contenido agregado fue correcto, solo las cifras reportadas mentían. Validación final con `git diff --stat` sigue siendo el único ground truth.
