## 🎯 Hallazgos clave (5+1)

### (a) Vitamin A — escalado limitado por Impression Share
```
Vitamin A Power (Phrase):
  - ACoS:              32% ← verde
  - Orders:            3/día ← volumen sano
  - Impression Share:  8% ← CRÍTICO
  - Product Sale %:    18–100% (rango mercado 18–100%)
  - Precio nuestro:    $9.99
  - Precio mercado:    $13.99 promedio
```

**Diagnóstico:** No es calidad (PS al techo), es penetración. Con IS 8%, perdemos 92% de impresiones ganables.  
**Oportunidad:** subir bid 25–40% → IS destino 15–20% → +2–3 orders/día adicionales a mismo ACoS (mercado estira volumen antes de que CPC suba).

### (b) Fuga de marca — Brand Hub Defensive sub-bideada

Brand Hub (Exact KWs marca):

## 🧠 Learning operativo

### Bug de búsqueda: BSE (Bulk Sheet) enabled-only filtering

**Síntoma:** Hipoglós Conquest reportado como "inexistente" al grep en Campaign CSV.

**Causa raíz:** Bulk Sheet export filtra automáticamente `State == "ENABLED"`. Campañas pausadas no aparecen en la descarga estándar.

**Consecuencia:** Lenin creó un Create nueva campaña Hipoglós Conquest → rebotó con "campaign name already exists in account", revelando que la verdadera existía, estaba PAUSADA.

**Regla para futuro:**
```
ANTES de dar una campaña por inexistente:
  1. Grep en Campaign CSV cargado (enabled only)
  2. Grep en STR/SQP (da 0 líneas si pausada)
  3. Manualmente en Ads Manager UI o BSE filters con State="All"
  
Orden importa: el UI puede mentir, el Ads Manager no.
```
