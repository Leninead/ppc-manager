### Pattern de oro adoptado (Plan D)
- Buffer mutable en `st.session_state[f"ps_buffer__{pid}"]` con sub-dict por block
- Widgets SIN `key=`, solo `value=buf[campo]` + captura del retorno → asignación inline al buffer
- `st.button` (NO `st.form_submit_button`)
- Commit explícito vía función pura `_build_v1_payload` → `_commit_v1_to_disk` → `save_proposal`
- Invalidate selectivo del buffer del block tras commit (otros blocks sobreviven)
- Skip-save guard: comparación estricta payload-normalizado vs disco antes de cada save

### Anti-patterns documentados (evitar en B3-c+)
- `st.form` + `st.form_submit_button` con widgets `value=`/`key=` → bug rehidratación Streamlit 1.43.2
- `st.session_state.setdefault(key, default)` adyacente a widget con `key=` → cancela silenciosamente el packet del cliente
- `st.expander` envolviendo `st.form` → form pierde identidad entre reruns cuando expander cambia de estado
- Combo "leer-de-disco-cada-rerun + setdefault + form submit" → frágil, abandonado
