## Bugs y gotchas de bulks — para no volver a tropezar

Estos descubrimientos de hoy son críticos para futuras sesiones. Documentados también en [[amazon-bulk-upload-guide]].

### 1. Negative Keyword vs Campaign Negative Keyword (DOS entities distintas)

| Entity | Aplica a | Requiere Ad Group ID |
|---|---|---|
| `Negative Keyword` | Nivel **Ad Group** | Sí (sin él falla "Missing Parent ID") |
| `Campaign Negative Keyword` | Nivel **Campaña** | No |

Bulk 05 falló al primer intento con "Negative Keyword" sin Ad Group ID. Fixed con `Campaign Negative Keyword`.

### 2. Campaign IDs numéricos para campañas existentes

| Caso | Campaign ID / Ad Group ID |
|---|---|
| Crear campaña + ad group + keywords en el **mismo bulk** | Usar **Campaign Name** (string). Amazon hace match interno. |
| Crear keywords/negativos en **campañas YA existentes** | Usar **ID numérico real** (descargar BulkSheetExport antes). |
| Update bids / Update state | Usar **ID numérico real** |

Bulk 05 v2 falló al segundo intento con Campaign Name string. Fixed cruzando contra BulkSheetExport para extraer Campaign IDs numéricos.

### 3. Start Date debe ser TEXTO no float

- OK: `20260428` (string)
- Falla: `20260428.0` (float, Amazon rechaza)

Fix en código:

```python
cell.number_format = "@"
value = str(value).split(".")[0]
```

### 4. Google Sheets corrompe IDs numéricos largos

Si abrís el bulk en Google Sheets, los IDs como `497286372972562` se transforman a notación científica `4.97E+14`. NO abrir en Sheets antes de subir. Subir el .xlsx original directo de Claude.

### 5. Match types soportados por Campaign Negative Keyword

Solo `negativeExact` y `negativePhrase`. NO soporta `negativeBroad`.

### 6. Keywords con caracteres especiales

- `%` → rechazado (`allantoin 0.5% cream` falló)
- Punto + decimal puede causar problemas

### 7. Campaign Analyzer puede mostrar campañas YA ELIMINADAS

El campaign_analyzer__5_.xlsx mostraba 114 campañas, el BulkSheetExport real tiene 84. Las 30 zombies del analyzer ya estaban eliminadas. **Cruzar siempre con BulkSheetExport antes de tomar decisiones de pausa**.

### 8. SD bulk uses different schema (47 cols vs 31 cols SP)

Si vas a manipular SD via bulk, las columnas son distintas (incluye Tactic, Bid Optimization, Cost Type, Targeting Expression).
