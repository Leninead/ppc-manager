# SOPs — Índice por audiencia

Los SOPs están separados en tres carpetas según a quién le sirven. Si sos dev
nuevo, tu carpeta es `dev/`.

## dev/ — Proceso de desarrollo interno
Cómo trabajamos el código: worktrees, branches, cierre de sesión, gotchas de
Streamlit. Lectura obligada para cualquiera que toque el repo.

## usuario/ — Manuales de usuario final
Guías paso a paso para AMs y usuarios no técnicos (Marcos, etc.) sobre cómo usar
los módulos. No relevante para desarrollo.

## agencia/ — Metodología PPC y procesos operativos
El know-how de la agencia: reportes, bulks, Atom11, attribution. Relevante para
quien opera cuentas, no para quien desarrolla.
