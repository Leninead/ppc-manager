## 🔧 Conocimiento técnico — Bulk Amazon MX

### Estructura correcta para campañas NUEVAS (aprendido sesión 1)
```
Campaign ID  = Campaign Name  (referencia interna temporal — Amazon lo resuelve)
Ad Group ID  = Ad Group Name  (igual)
Operation    = create en TODAS las filas sin excepción
```
Este es el mismo patrón que funciona en los bulks de Setex. No usar IDs numéricos para operaciones create.

### Errores documentados y sus fixes
| Error | Causa | Fix |
|-------|-------|-----|
| Missing Parent ID (59 errores) | Campaign ID vacío en filas hijas | Campaign ID = Campaign Name |
| Campaign already exists | Segunda pasada sobre campaña ya creada | Archivar duplicados, recrear todo |
| Invalid ID en update | `update` no acepta nombre como ID, solo numérico | Archivar y recrear con `create` |
| Bidding Adjustment huérfano | Sin fila Campaign de contexto | Archivar y recrear — no mezclar update+create |
| **Solución final** | Todo `create` + Campaign ID = Campaign Name | ✅ 42/42 rows processed |
| **Config sheet inválida** | Sheet Config con headers incorrectos bloquea TODO el upload | Eliminar sheets vacías (Config, Portfolios, SB, SD) — solo dejar SP Campaigns |

### Valores válidos Amazon MX
```
Targeting Type:   MANUAL / AUTO  (no AUTOMATIC — da error)
Placement:        placementTop   (no "Top of Search on-Amazon" — da error)
Bidding Strategy: Fixed bid
Match Type:       exact / phrase / broad
Negative Match:   negativeExact / negativePhrase
Portfolio ID:     vacío — asignar manualmente desde Campaign Manager
```

PVM | [ASIN] | MX | SP-KWS | EXACT | RANK    | [keyword]
