# _archive — Histórico con valor

Archivos que ya no están en circulación pero se conservan por valor histórico o
trazabilidad. NO se borran. Versionados en git.

- docs/ — documentos y SOPs superados por versiones más nuevas.
- scripts/ — scripts one-shot ya aplicados (deploy fixes, etc.).

Si buscás la versión vigente de algo que está acá, revisá primero notes/sops/ o
la raíz del repo.
